How does an LLM turn my question into an answer?

26 October 2026 ·8 page comic

While learning how LLMs work, I kept coming back to a few questions. If the model only takes numbers, what happens to my text? Why can it process the question together, but generate the answer one token at a time? Does it process the whole question again at every step?

I turned that learning into this 8-page comic. It follows one question about a cat through token IDs, sampling, weights, prefill, decode and KV caching.
